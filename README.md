# Human-Centric System Design

*A Literature Review on Increasing the Practical Application of HCI in Software Projects*

Literature review, 2025 · Course: Mind Meets Machine: Cognitive and Social Perspectives on Social Robotics

## Abstract

This literature review explores some common challenges encountered by operating systems engineers that aren't human-computer interaction (HCI) specialists in designing interactive systems, examining how these issues have been investigated in recent scholarly work. The review first identifies the scope and depth of existing studies, emphasizing their varying degrees of relevance and methodological rigor. It then synthesizes the most prominent solutions proposed in the literature, highlighting how each solution addresses different facets of user requirements and system constraints. Although there are approaches that have demonstrated promise, there remains a lack of cohesive strategies for integrating these findings into a unified conceptual framework for real-world-scenario tasks. Recognizing this gap, the review stresses the potential for new research dedicated to developing and refining methods that better balance the array of requirements — from usability to technical feasibility — that define successful interactive system design. By delineating both the achievements and outstanding shortcomings of current methodologies, this review underlines the need for further investigation into a more holistic, user-centered approach that can inform future innovations in the field.
